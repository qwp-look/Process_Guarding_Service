winapp launcher provider

Provider-class module (default opt-in). Implements WindowsApps AUMID activation mechanics used by the service restart path (appKind=winapp) and by pgs_bless bless-start --winapp.

Enable with pgs_service install --enable-launchers or load on demand via module load --path modules\winapp\pgs_winapp_module.dll.

Request surface: op=activate;aumid_b64=<b64>;args_b64=<b64> — responds OK pid=<pid>.
