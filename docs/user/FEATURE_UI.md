# 界面与远程查看

PGS 提供三类界面：Qt 管理端、Web 管理端、Cluster 面板。

## Qt 管理端

Qt 管理端适合普通本机用户：

- 填 token。
- 添加或启动守护对象。
- 查看守护列表。
- 修改重启策略。
- 调用模块入口。

普通用户优先使用 Qt 管理端。

## Web 管理端

Web 管理端适合在浏览器中管理本机 PGS，或由维护者配置为远程管理入口。

默认本地模式只绑定回环地址。远程模式必须显式配置 TLS、用户文件和审计日志，避免把管理入口直接暴露到网络。

远程配置细节见 [维护者操作指南](../operator/OPERATOR_GUIDE.md)。

## Cluster 面板

Cluster 面板用于集中查看多个 PGS 节点。

- 本地默认模式只监听 `127.0.0.1`。
- 非回环监听需要 TLS 和 dashboard API token。
- 节点凭据和远程 TLS 校验属于维护者配置范围。

普通用户只需要知道：Cluster 是“看多台机器状态”的面板，不是单机守护的必需组件。


## 守护总览页（任务管理器风格）

Qt 管理端的第一个页签是任务管理器风格的"守护总览"：

- 树形视图：顶层为分组（未分组的守护在"默认"下），中间是守护对象（名称、PID、状态、保护时长、触发保护次数、健康度、上次失败），展开守护对象可以查看其 Job Object 内的进程族成员。
- 右键菜单：添加保护、关闭保护、立即退出并解除、隔离态的重试/清除、加入/移除分组、分组暂停/恢复/重启、属性详情。
- 工具栏：添加保护、暂停/恢复刷新、刷新间隔（1/2/5/10 秒）、按名称过滤、host/port 设置。
- 数据通过管理协议直连服务获取（无需每次刷新启动命令行进程）；仅"添加保护"因需要本机启动进程而调用一次 pgs_bless。
