# 界面与远程查看

PGS 提供三类界面：Qt 管理端、Web 管理端、Cluster 面板。

## Qt 管理端

Qt 管理端适合普通本机用户：

- 填 token。
- 添加或启动守护对象。
- 查看守护列表。
- 修改重启策略。
- 调用模块入口。

普通用户优先使用 Qt 管理端。

## Web 管理端

Web 管理端适合在浏览器中管理本机 PGS，或由维护者配置为远程管理入口。

默认本地模式只绑定回环地址。远程模式必须显式配置 TLS、用户文件和审计日志，避免把管理入口直接暴露到网络。

远程配置细节见 [维护者操作指南](../operator/OPERATOR_GUIDE.md)。

## Cluster 面板

Cluster 面板用于集中查看多个 PGS 节点。

- 本地默认模式只监听 `127.0.0.1`。
- 非回环监听需要 TLS 和 dashboard API token。
- 节点凭据和远程 TLS 校验属于维护者配置范围。

普通用户只需要知道：Cluster 是“看多台机器状态”的面板，不是单机守护的必需组件。


## 守护总览页（任务管理器风格）

Qt 管理端的第一个页签是任务管理器风格的"守护总览"，显示系统里的**所有进程**（父进程 → 子进程的树形结构，与任务管理器一致），并叠加守护状态：

- 列：名称、PID、状态（未保护进程显示"运行中"；受保护进程绿色显示"受保护/已暂停/已隔离"）、CPU、内存；受保护的进程额外显示保护时长、触发保护次数、分组和上次失败原因。
- 右键未受保护的进程：**保护此进程**（直接按 PID 注册守护，可设置重启上限）。
- 右键受保护的进程：关闭保护、立即退出并解除、隔离态的重试/清除、加入/移除分组、分组暂停/恢复/重启、属性详情。
- 顶部：已隔离但无活跃进程的守护记录会以红色置顶显示。
- 工具栏：启动并保护新程序（调用一次 pgs_bless bless-start）、只看受保护/显示全部切换、暂停刷新、刷新间隔（1/2/5/10 秒）、按名称过滤、host/port。
- 进程列表由界面本地枚举（任务管理器同款 API），服务不可达时进程列表仍然可用，只是守护状态叠加会缺失；守护状态通过管理协议直连获取。
